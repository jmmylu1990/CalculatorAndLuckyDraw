# amway

本專案是一個基於 Spring Boot 與 Thymeleaf 的網頁計算機，支援兩個數的加、減、乘、除計算，並提供完整的復原（Undo）與重做（Redo）功能。

## 設計特點

### 1. 命令模式（Command Pattern）
專案採用命令模式來實作 Undo 與 Redo。所有的運算（加、減、乘、除）都被封裝成獨立的命令物件。
與傳統「使用逆運算（如 Undo 加法就用減法）來復原」的做法不同，本專案在執行命令時會直接記錄執行前的數值（prevValue）。
這樣做的好處是：
- 避免除法中可能遇到的除以零錯誤。
- 避免浮點數運算帶來的精度累積誤差。

### 2. 無刷新單頁體驗（AJAX）
首頁透過 Thymeleaf 進行初始渲染，後續的所有計算、Undo、Redo 及清除操作均透過瀏覽器原生的 Fetch API 發送非同步請求，並動態更新網頁 DOM，提供流暢的單頁操作體驗。

### 3. Session 狀態隔離
計算機的狀態（目前數值、Undo 棧、Redo 棧）儲存在 HTTP Session 中，確保不同使用者或瀏覽器視窗之間的計算歷史完全獨立。

### 4. 鍵盤快捷鍵支援
除了滑鼠點擊外，也支援實體鍵盤操作：
- 數字、小數點及運算子鍵（+, -, *, /）。
- Enter 或 = 鍵進行計算。
- Backspace 進行退格。
- Ctrl+Z（或 Cmd+Z）進行復原（Undo）。
- Ctrl+Y（或 Cmd+Y）進行重做（Redo）。

## 開發環境
- Java 21
- Maven 3.9.6
- Spring Boot 3.3.3

## 執行步驟

### 1. 啟動服務
在專案根目錄下執行以下指令：
```bash
./mvnw spring-boot:run
```

### 2. 存取網頁
開啟瀏覽器並造訪：
http://localhost:8080

### 3. 執行測試
專案包含針對計算邏輯與 Undo/Redo 棧的單元測試，執行以下指令跑測試：
```bash
mvn test
```
