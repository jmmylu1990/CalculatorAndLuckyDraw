# amway

本專案是一個基於 Spring Boot 與 Thymeleaf 的多功能網頁應用，包含「計算機」與「電商抽獎轉盤」兩個核心模組。

## 功能模組

### 1. 復原 (Undo) 與重做 (Redo) 計算機
> **設計目標**：設計一個計算機（Calculator），可執行兩個數的加、減、乘、除計算，並支援 **Undo（復原）** 與 **Redo（取消復原 / 重做）** 操作，並在實現功能的基礎上進行最佳化設計。

*   **基礎運算與 Undo / Redo**：
    *   支援兩個數的加、減、乘、除計算。
    *   提供完整的 **Undo（復原）** 與 **Redo（取消「上次復原」）** 功能，允許在計算歷史中來回切換。
*   **命令模式（Command Pattern）**：將每個運算封裝成獨立的命令。在執行命令時會直接記錄執行前的數值（`prevValue`）。
*   **最佳化設計**：當點擊「復原 (Undo)」按鈕時，系統會自動在畫面上點亮並還原被撤銷的運算子，使用者可以直接輸入新數值並點擊 `=` 來修正上一筆計算，大幅提升使用者體驗。

### 2. 電商轉盤抽獎
- **獎品與機率配置**：
  - iPhone 15 Pro：數量 3，機率 1%
  - iPad Air：數量 10，機率 5%
  - AirPods Pro：數量 20，機率 14%
  - 銘謝惠顧：機率 80%
- **併發安全防超抽（防超賣）**：後端抽獎服務使用 `ReentrantLock` 鎖定核心抽獎區塊，保證在高併發同時抽獎的環境下，獎品剩餘數量能夠被原子化扣減，絕對不會發生獎品超抽（數量小於 0）的情況。若獎品被抽完，會自動轉為「銘謝惠顧」。
- **防重複提交（防重複抽獎）**：控制器使用 HTTP Session 鎖定機制。當使用者的抽獎請求正在處理時，其後續的重複點擊將被直接拒絕。
- **多次抽獎**：支援單次抽獎、連續抽獎 5 次、連續抽獎 10 次的操作，網頁上會展示每次的抽獎結果清單。

## 開發環境
- Java 21
- Maven 3.9.6
- Spring Boot 3.3.3

## 執行步驟

### 1. 啟動服務
在專案根目錄下執行以下指令：
```bash
./mvnw spring-boot:run
```

### 2. 存取網頁
- 計算機頁面：http://localhost:8080
- 抽獎轉盤頁面：http://localhost:8080/lottery
- （頁面左上方設有快速切換的導覽連結）

### 3. 執行測試
專案包含針對計算邏輯、Undo/Redo 棧以及高併發抽獎安全性的單元測試。執行以下指令跑測試：
```bash
mvn test
```
